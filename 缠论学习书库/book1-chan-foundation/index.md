# 导读

![封面：缠论结构基础](assets/cover.svg)

> 本书解决一个基础问题：缠论里的结构不是凭感觉画线，而是从 K 线、分型、笔、线段和中枢一步步推导出来的。

这不是交易动作手册，而是语言训练。读完这一册，目标是能听懂并复述“一个结构为什么成立、为什么不成立、哪里仍是候选”。

3. [第 2 章 笔与线段](02-笔与线段.md)
4. [第 3 章 中枢与走势类型](03-中枢与走势类型.md)
5. [第 4 章 背驰与买卖点](04-背驰与买卖点.md)
6. [附录 A 练习入口](appendix-a-exercises.md)
