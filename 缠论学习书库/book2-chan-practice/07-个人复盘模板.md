# 07 个人复盘模板

## 这一章解决什么问题

学到最后，需要把概念变成固定复盘问题。

否则每次看盘都会重新纠结：这是不是上涨？这里能不能买？跌破了要不要出？时间久了又会回到凭感觉。

## 每次复盘固定九问

### 1. 当前观察级别是什么？

日线、周线、小时线，不要混用。

### 2. 当前结构是什么？

上涨、下跌、震荡、突破中、回踩中，还是证据不足？

### 3. 最近有效高低点在哪里？

能不能说清楚为什么这个高点/低点有效？

### 4. 防守位在哪里？

如果是上升趋势，最近保护趋势的有效回调低点在哪里？

### 5. 压力位在哪里？

如果是下降或破防后修复，最近需要突破的小高点在哪里？

### 6. 现在是观察、确认、延续、尾声，还是失败？

不要直接说“买”或“卖”，先说状态。

### 7. 如果入手，失败线在哪里？

没有失败线，就不要把它当成完整动作。

### 8. 如果错了，亏损是否可控？

看得懂不等于能承受。

### 9. 下一根或后面几根 K 线要验证什么？

比如：

- 是否收盘站上压力位？
- 是否回踩不破？
- 是否跌破防守区下沿？
- 是否再次创新低？

## 复盘记录模板

```text
标的：
日期：
观察级别：

一、当前结构
- 趋势状态：
- 有效高点：
- 有效低点：

二、关键线
- 防守区：
- 压力位：
- 震荡上沿：
- 震荡下沿：

三、当前状态
- 观察 / 普通确认 / 稳健确认 / 趋势延续 / 趋势尾声 / 失败：
- 判断理由：

四、动作计划
- 当前动作：
- 如果确认：
- 如果失败：

五、失败线
- 失败线位置：
- 失败原因：
- 可承受亏损：

六、下一步验证
- 下一根/下几根 K 线重点看：
```

## 本书最后的核心句

趋势结构 → 防守位/压力位 → 观察区 → 确认点 → 失败线 → 仓位动作。

只要这个顺序不乱，看盘就会清楚很多。
