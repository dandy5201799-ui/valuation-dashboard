# 05 仓位动作：不同状态做不同大小的动作

## 这一章解决什么问题

前面讲的是怎么看结构。现在要讲动作。

动作不是只有“买”和“卖”。如果只会二选一，就容易在观察区冲进去，也容易在趋势只是变弱时一下子全卖光。

更合理的做法是：不同结构状态，对应不同大小的动作。

## 七种动作

### 1. 观察

还没有确认点，只是价格到了关键区域。

动作：不动，最多做记录。

例如：回调到防守区附近，或者跌到震荡下沿附近。

### 2. 小仓试错

出现普通确认，但还不是最稳健。

动作：可以小仓试错，但必须有失败线。

例如：收盘突破下降小高点，或者重新站上破防后的压力位。

### 3. 正常仓位

普通确认之后，又完成回踩不破、再次转强。

动作：可以考虑正常仓位。

这里的重点不是“更确定”，而是失败线更清楚，错误更容易承担。

### 4. 趋势持有

趋势还在延续，没有有效破防。

动作：持有，同时上移防守位。

上涨趋势中，不要因为涨了一点就急着卖。真正要看的，是最近确认低点有没有被破坏。

### 5. 趋势尾声减仓

价格仍然可能创新高，但动能开始变弱。

常见表现：

- 新高幅度变小；
- 回调变深；
- 反弹无力；
- 靠近防守区的次数变多；
- 出现顶背驰候选。

动作：不追高，收紧防守，可以逐步减仓。

### 6. 有效破防退出

如果有效跌破防守区，原上升结构被破坏。

动作：退出或明显降仓。

注意：破防后不是不能再买回来，而是不能用旧逻辑立刻接回。必须等新的修复确认。

### 7. 修复成功接回

破防之后，如果重新突破破防后的新压力位，并且回踩守住，再次转强，可以考虑接回。

动作：接回，但同样要有新的失败线。

## 动作和失败线绑定

| 状态 | 动作 | 失败线 |
|---|---|---|
| 观察区 | 不动 | 观察失效线，不是交易止损 |
| 普通确认 | 小仓试错 | 跌回突破线下方，或跌破试错 K 低点 |
| 稳健确认 | 正常仓位 | 跌破回踩低点 / 新防守位 |
| 趋势持有 | 持有 | 跌破最近确认低点 |
| 趋势尾声 | 减仓观察 | 原防守区 |
| 有效破防 | 退出或大幅降仓 | 不用旧防守位做买点 |
| 修复接回 | 重新建仓 | 跌破修复回踩低点 |

## 本章小结

买入之后，第一判断不是“涨了开心、跌了害怕”，而是：

1. 是否守住当前防守位？
2. 如果守住，有没有趋势尾声迹象？
3. 如果没破防，只是变弱，减仓或观察，不急着全走。
4. 如果有效破防，先离场或明显降仓。
5. 破防后如果重新修复，才考虑接回。
6. 反弹不过压力，或者再创新低，就不接回。

“破防后接回”不是看到涨回来就接，而是要重新完成确认。
