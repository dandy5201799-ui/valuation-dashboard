# 04 从真实 K 线画出趋势结构

## 本节目标

前三章讲的是判断逻辑：

- 第 1 章：看现在是什么趋势；
- 第 2 章：价格到了关键线附近，怎么从观察机会走到确认机会；
- 第 3 章：如果买早了，或者确认后失败了，怎么承担错误。

> 编辑进度：本章内容后续会迁移到新第 2 章，专门讲“从真实 K 线画出走势”。

但这些逻辑都还有一个前提：

> 你得先能从真实 K 线里，把趋势结构画出来。

如果不会画结构，后面的防守位、压力位、观察区、确认点都会变成凭感觉。

所以第 4 章不是单纯“复盘历史 K 线”，而是解决一个更基础的问题：

> 怎样把一堆真实 K 线，整理成可以判断趋势的高低点和波段？

## 先说清楚：K 线不会天然告诉你趋势

真实 K 线每天都有高点、低点、开盘价、收盘价。

但趋势不是把每天的点都连起来。

如果每天都连，你看到的只是一堆噪音：

```text
今天涨一点
明天跌一点
后天又拉一下
```

真正要看的，是一段走势里比较关键的转折点：

- 哪些地方形成了阶段高点；
- 哪些地方形成了阶段低点；
- 后一个高点是不是比前一个高；
- 后一个低点是不是比前一个高；
- 或者反过来，高点、低点是不是都在降低。

这就是把 K 线整理成趋势结构。

## 第一步：先找局部高点和局部低点

最简单的入门标准是：

> 局部高点：这根 K 线的高点，比前后几根 K 线都高。  
> 局部低点：这根 K 线的低点，比前后几根 K 线都低。

注意，这里不是看收盘价，也不是每天都选。

我们看的是 K 线的最高价和最低价，因为高点、低点本来就是价格波动到过的位置。

但也不能太机械。一个有效高低点，至少要满足两件事：

1. 它在视觉上是这一小段走势的转折处；
2. 它和前后点之间有一定距离，不能几根 K 线挤在一起反复算点。

如果点太密，画出来的不是趋势，而是毛刺。

## 第二步：把有效高低点连成波段

找到高低点以后，不是随便连。

要按时间顺序，把高点和低点交替连起来：

```text
低点 → 高点 → 低点 → 高点
```

或者：

```text
高点 → 低点 → 高点 → 低点
```

如果连续出现两个高点，只保留更高、更明显的那个。

如果连续出现两个低点，只保留更低、更明显的那个。

这一笔连出来的线，不是为了好看，而是为了回答：

> 当前这段走势，是高低点在抬高，还是高低点在降低，还是来回重叠？

## 第三步：用高低点判断趋势

趋势判断只看一件事：

> 高点和低点有没有形成方向。

### 上升趋势

如果后一个高点比前一个高，后一个低点也比前一个高，就是上升结构。

```text
低点抬高 + 高点抬高 = 上升趋势
```

### 下降趋势

如果后一个高点比前一个低，后一个低点也比前一个低，就是下降结构。

```text
高点降低 + 低点降低 = 下降趋势
```

### 震荡

如果高点没有明显抬高，低点也没有明显降低，而是在一个区间里反复来回，就是震荡。

```text
高低点互相重叠 = 震荡
```

所以，趋势不是靠一根大阳线或一根大阴线判断。

一根大阳线只能说明当天很强；能不能成为趋势，要看它有没有让后面的高低点结构改变。

## 第四步：根据趋势画关键线

画出趋势结构以后，才能画关键线。

上升趋势里，最重要的是最近有效低点。它通常形成防守位或防守区。

因为上升趋势的核心是：

> 低点不能持续跌破，低点最好越来越高。

如果最近有效低点被跌破，上升结构就开始出问题。

下降趋势里，最重要的是最近有效高点。它通常形成压力位或压力区。

因为下降趋势的核心是：

> 高点不能持续突破，高点最好越来越低。

如果最近有效高点被突破，下降结构就开始修复。

震荡里，关键线是区间上沿和区间下沿。

## 第五步：关键线附近只是观察区

这一步接回第 2 章。

画出关键线以后，不是说价格一到关键线就可以买或卖。

价格到防守位、压力位、震荡边界附近，只能说明：

> 这里开始值得观察。

后面要看有没有确认：

- 向上修复，看是否收盘突破最近小高点；
- 向下破坏，看是否收盘跌破最近小低点；
- 有二次回踩/反抽时，看二次是否守住；
- 没有二次回踩/反抽时，看最近局部关口是否被收盘打破。

## 第六步：动作之前必须带失败线

这一步接回第 3 章。

如果你只是观察区提前买，那么失败线通常放在观察区另一侧。

例如上升趋势回调到防守区，你提前买了：

```text
买入理由：防守区会守住
失败线：防守区下沿
处理：有效跌破防守区下沿，认错退出或降仓
```

如果你是确认点之后买，那么失败线要跟着确认理由走。

例如下降趋势中突破压力位后买入：

```text
买入理由：下降结构开始修复
失败线：跌回突破位下方，或跌破修复回踩低点
处理：突破失败，就承认这次转强失败
```

## 本章配套练习：不要单独练，要跟着步骤练

这个练习不是放在最后随便做一下，而是应该配合本章一步一步做：

1. 先在真实 K 线里点出你认为有效的高点和低点；
2. 把这些点连成波段；
3. 判断当前是上升、下降、震荡，还是证据不足；
4. 画出防守位、压力位或震荡边界；
5. 标出观察区；
6. 找右侧确认点；
7. 写出失败线和对应动作。

配套练习器：

- [第六关：真实历史K复盘练习器](../../03_练习器/缠论第六关_真实历史K复盘练习器.html)

每次练习都要写完整句子，而不是只写“看涨”或“看跌”：

```text
当前看的是日 K 线。
我选出的有效波段是：低点 A → 高点 B → 低点 C → 高点 D。
因为 C 高于 A，D 高于 B，所以当前是上升结构。
最近有效低点 C 是防守位。
价格回到防守区附近，只是观察区。
如果后面二次不破，并收盘突破回调小高点，才是确认点。
如果有效跌破防守区下沿，就说明这次观察失败。
```

## 本章小结

第 4 章真正要解决的是：

> 怎么从真实 K 线，走到趋势结构。

顺序不能乱：

```text
真实 K 线
→ 有效高低点
→ 波段
→ 趋势判断
→ 关键线
→ 观察区
→ 确认点
→ 失败线
→ 动作
```

如果前面没有画出有效高低点和波段，后面的趋势、防守位、确认点都会变成凭感觉。
