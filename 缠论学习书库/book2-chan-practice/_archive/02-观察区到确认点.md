# 02 从观察机会到确认机会

## 本节目标

> 编辑进度：本章仍是迁移前版本。按新结构，第 2 章将改为“从 K 线画出走势”；关键线会放到第 3 章完整讲。

第一章先解决的是：当前是什么趋势。

第二章解决的是机会确认问题：

> 价格走到关键线附近，是不是出现了买入或卖出的机会？如果只是可能，怎样确认这个机会成立？

这是本章的核心。

这里的“机会”，不只指买入机会，也包括卖出、减仓、接回、继续持有的机会。

价格到了关键线附近，常常会让人以为“机会来了”：

- 上升趋势回调到防守区，好像可以买；
- 上升趋势跌破防守区，好像应该卖；
- 下降趋势站上压力区，好像可以试错买入；
- 震荡走势碰到上沿或下沿，好像要突破或反弹。

但到了关键线附近，不等于机会已经成立。它只说明：这里可能出现机会，值得观察。

这就是“观察区”。

观察区不是随便画出来的，它来自第一章讲的关键线：

- 上升趋势里，价格回到防守位/防守区附近，这是观察区；
- 上升趋势里，价格有效跌破防守区附近，也会进入卖出/减仓观察；
- 下降趋势里，价格反弹到压力位/压力区附近，这是观察区；
- 震荡里，价格来到上沿或下沿附近，这是观察区。

本章要讲的，就是一个“可能机会”怎样变成“确认机会”。

我们把它拆成三个层次：

1. 观察机会：价格到了关键线附近，但还不能动作。
2. 第一层确认：右侧走势出现收复、跌破、突破小高点、站上压力位等证据。
3. 更稳健确认：确认之后回踩/反抽不破，再次转强或转弱，机会质量更高。

## 统一流程

最重要的一句话是：

> 观察区只说明“这里可能有机会”，确认点才说明“这个机会开始被右侧走势证明”。

## 四类常见机会

### 1. 上升趋势回调

价格回到防守区附近，不代表可以买。严谨一点的路径是：

1. 回调到防守区附近；
2. 没有有效跌破防守区；
3. 出现反弹；
4. 二次回落不破；
5. 再向上突破回调小高点。

这个“突破回调小高点”的位置，才更接近确认点。

### 2. 下降趋势转强

下降趋势里，不能因为跌多了就买。要看下降结构是否开始被破坏。

常见确认路径是：

1. 找到最近下降小高点或压力位；
2. 收盘站上压力位，形成普通确认；
3. 突破后回踩不破；
4. 再次转强，形成更稳健确认。

注意，这里强调“收盘站上”，盘中冲一下不算。

### 3. 震荡下沿修复

震荡下沿附近也不是天然买点。下沿只是观察区。

比较稳妥的路径是：

1. 到达或刺破震荡下沿；
2. 重新收回区间；
3. 反弹形成修复小高点；
4. 回踩不再跌破下沿；
5. 再次突破修复小高点。

### 4. 震荡上沿突破回踩

突破震荡上沿之后，也不要只看突破当天。

更稳健的路径是：

1. 收盘突破震荡上沿；
2. 回踩到上沿附近；
3. 没有有效跌回原震荡区间；
4. 再次反弹并突破回踩后的短线小高点。

这样才更像“突破后站稳”。

## 没有二次回踩/反抽时，怎么确认

前面讲的是比较标准、比较稳的确认：

> 到观察区 → 第一次反应 → 二次回踩/反抽 → 不破关键区 → 再次突破/跌破 → 确认。

但真实走势里，有时候不会给你二次回踩或二次反抽，而是直接走强或直接走弱。

这时候不要把它讲成一个新体系，只需要记住一句话：

> 没有二次确认时，就看最近一个局部关口有没有被收盘打破。

### 1. 向上：强势突破

如果价格到观察区后，没有明显二次回踩，而是直接向上走：

```text
观察区
→ 直接反弹
→ 收盘突破最近小高点 / 小平台上沿
→ 第一层确认
```

这里确认的不是“已经绝对安全”，而是：

> 多方已经直接打过最近压力位，走势开始转强。

但它没有二次回踩验证，所以稳健性不如“回踩不破后再突破”。

![直接突破小高点如何确认](diagrams/自动图_直接突破小高点确认.svg)

![防守区上方小平台上沿](diagrams/自动图_防守区上方小平台上沿.svg)

这里的“小高点”通常不是随便一个小红点，而是最后一段明显回落前形成的局部高点，或者防守区上方小平台的上沿。

关键是你必须能说清楚：它收盘突破的到底是哪条线。

### 2. 向下：强势跌破

向下也一样。如果价格到防守区附近后，没有明显二次反抽，而是直接向下走：

```text
防守区
→ 直接下跌
→ 收盘跌破最近小低点 / 防守区下沿
→ 第一层确认
```

这里确认的是：

> 空方已经直接打穿最近防守位，走势开始转弱。

但它也没有二次反抽验证，所以后面还要看会不会快速收回。

![强势跌破如何确认](diagrams/自动图_强势跌破确认.svg)

所以这一节不是新增复杂概念，而是在补充一个现实情况：

> 有二次回踩/反抽，就按标准确认；没有二次回踩/反抽，就看最近小高点或小低点是否被收盘打破。  
> 向上叫强势突破，向下叫强势跌破。它们都只是第一层确认。

## 本章小结

第二章不是直接回答“能不能买”，而是回答：

> 这里是不是出现了机会？如果是，这个机会有没有被确认？

判断顺序是：

1. 先判断当前属于哪种结构；
2. 再找对应关键线；
3. 价格到关键线附近，只能叫观察机会；
4. 右侧走势给出突破、跌破、收复、站上压力等证据，才是第一层确认；
5. 确认后回踩/反抽不破，再次转强或转弱，才是更稳健确认；
6. 没有二次回踩/反抽时，向上看收盘突破最近小高点，向下看收盘跌破最近小低点；
7. 如果确认失败，后面要按失败线处理。
