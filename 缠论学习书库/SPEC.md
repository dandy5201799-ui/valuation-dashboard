# 缠论学习书库项目规范

更新时间：2026-09-15

## 项目目标

这个目录维护两类内容：

1. `book2-chan-practice/`：当前主书《看懂K线走势》，把缠论知识放进真实看图问题里讲。
2. `book3-auto-marker/`：配套书《缠论标记工具》，说明辅助标记工具应该画什么、怎么解释、如何验证。

这不是荐股项目，也不是自动交易系统。所有内容都服务于学习、标记、解释和复盘。

## 当前有效目录

| 路径 | 用途 | 提交策略 |
|---|---|---|
| `book2-chan-practice/` | 主书源码、章节、配图、封面、样式 | 提交 |
| `book3-auto-marker/` | 工具说明书源码、章节、配图、封面、样式 | 提交 |
| `tools/` | 统一构建脚本与 Honkit 辅助脚本 | 提交 |
| `PROJECT_STATUS.md` | 项目进展与下一步 | 提交 |
| `SPEC.md` | 本规范文件 | 提交 |
| `_archive/` | 旧书稿、早期素材、对话记录 | 可提交归档说明与关键稿件，不参与构建 |

## 构建产物

这些目录由构建命令生成，不作为源码维护：

- `book2-chan-practice/_book/`
- `book2-chan-practice/site/`
- `book3-auto-marker/_book/`
- `dist/`

这些目录已经写入 `.gitignore`。需要查看网页时重新构建即可。

## 依赖目录

`node_modules/` 只留在本地，不提交。依赖以 `package.json` 和 `package-lock.json` 为准。

## 归档原则

满足以下情况的内容放入 `_archive/`：

- 旧第一册，与当前合并后的《看懂K线走势》重复；
- 早期共用图示，已经被当前章节配图替代；
- 对话记录、阶段性草稿、旧版目录；
- 与当前 `SUMMARY.md` 不再相连的章节草案。

归档不是删除。需要追溯时可以看，但不再参与在线书库构建。

## 在线书库结构

统一入口由 `tools/build_chan_site.py` 生成，当前只展示两本书：

- 《看懂K线走势》
- 《缠论标记工具》

《看懂K线走势》的每篇文章底部会自动插入一个《缠论标记工具》的延伸阅读入口，位置在翻页控件下方。
