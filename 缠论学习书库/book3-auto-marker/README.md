# 导读

![封面：缠论标记工具](assets/cover.svg)

> 想找个工具帮你看K线图，直接告诉你哪里是买点？
>
> 别想了，这种工具不存在。
>
> 但我们可以做另一件事：把乱糟糟的K线图，变成能看懂的走势图。哪里是趋势、哪里是关键位置、哪里该观察、哪里确认了、错了在哪认——每一步都标出来，每一个标记都有依据。
>
> 这本书就是讲这个工具是怎么设计出来的：为什么要做、要画哪些东西、怎么分层、怎么摆、凭什么可信、怎么验证准不准。
